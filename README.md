MLBStats:

Description: The app interface provides an easy way for MLB fans to lookup basic peformance statistics 
on their favorite MLB players! The app provides up-to-date rosters, statistics on players, and standings. 
For people interested in advanced statistics, they can communicate with the built in OpenAi chatbot!

Technologies used:
. MLB Public API 
. Open AI API
. JavaScript Open AI SDK
. MVVM organization
. Custom Structs for data
. Passing data between custom views. @StateObject, @EnvironmentObject
. Map plotting
. Async Image loading
. JSON Parsing
